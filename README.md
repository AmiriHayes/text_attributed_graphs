# TACO-Graph: Automated Construction of Text-Attributed Graphs

Anonymous supplementary material for the submission *TACO-Graph: Automated
Construction of Text-Attributed Graphs*.

Choices about which entities become nodes, which relationships become edges,
and what text each node carries substantially affect downstream performance,
yet are usually made ad hoc. TACO-Graph enumerates the valid construction
space for a dataset and task, scores each variant with fast proxy evaluation
on small subsets, and fits an interpretable decision tree to those scores to
rank constructions without full-scale evaluation.

This repository contains the pipeline, the canonical run every reported number
comes from, and a one-command rebuild of every generated figure and table.

## Repository layout

```
code/          the TACO-Graph pipeline: sampling, construction, scoring, analysis
  graphrag/    question generation and RAGAS scoring
paper/         generators for every figure and table in the manuscript
  artifacts/   their output
data/          inputs only: configs, raw rows, sampled subsets, questions
output/
  run_final/   the canonical run every paper number comes from
```

## Reproducing the paper

```bash
python3 paper/build_all.py        # every generated figure and table, ~25s
python3 code/test_dt_consistency.py   # verification suite for the analysis
```

Both read `output/run_final/`, which is committed, so reproducing every figure
and table needs no retraining.

Figure 1 (`centerpiece_tag_paper.pdf`) is a hand-drawn diagram and is not
generated by this repo.

## Rebuilding `output/run_final/` from raw data

Only needed if you are changing the pipeline; it takes hours. Each step
depends on the one before it.

```bash
# 1. Raw rows, SBERT embeddings and the 1k-row subsets.
#    data/write_data.ipynb builds train/test frames, embeddings and samples
#    00-49; it has per-dataset cells for arxiv, amazon and history.
jupyter nbconvert --execute --inplace data/write_data.ipynb
python3 code/helpers/extend_samples.py        # samples 50-74, giving 75 per split

# 2. GNN scoring. The 10/10 default yields 20 subsets, not the 150 the paper
#    reports, so the sample counts must be passed explicitly.
python3 code/experiment_runner.py \
    --datasets amazon arxiv history electronics toys \
    --n_train_samples 75 --n_test_samples 75 \
    --output_path output/run_final

# 3. Questions and RAGAS scoring (needs OPENAI_API_KEY).
python3 code/graphrag/extend_questions_to_300.py
python3 code/graphrag/build_canonical_split.py   # writes question_split_*.csv
python3 code/graphrag/run_phase3b_graphrag_eval.py

# 4. Analysis consumed by the paper.
python3 code/dt_consistency.py --include_control
python3 code/build_table5_timing.py
```
